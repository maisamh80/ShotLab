# یادداشت انتشار ShotLab Desktop 1.0.0

ShotLab 1.0.0 نخستین نسخهٔ پایدار گردش کار تأییدشدهٔ کتابخانهٔ رفرنس تصویری
لوکال است.

- ساختار Sidebar در فارسی و انگلیسی یکسان و چپ‌چین باقی می‌ماند؛ آیکون‌ها
  همچنان در سمت چپ هستند و فقط متن رابط ترجمه می‌شود.
- بخش «یادداشت» در اطلاعات فریم گالری در هر دو زبان همیشه نمایش داده می‌شود؛
  حتی اگر هنوز یادداشتی برای فریم وارد نشده باشد.
- شمارهٔ نسخه در پایین Sidebar، اطلاعات برنامه و فایل اجرایی و Installer
  ویندوز به‌صورت یکسان روی 1.0.0 تنظیم شده است.
