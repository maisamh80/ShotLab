# ShotLab Desktop 1.0.0 Release Notes

ShotLab 1.0.0 is the first stable release of the approved local visual-reference
workflow.

- The Sidebar retains the same left-aligned structure in English and Persian;
  icons stay on the left and only the interface text is translated.
- The Notes section is always visible in Gallery frame information in both
  languages, including when a frame has no note yet.
- The Sidebar footer, application metadata, portable build, and Windows
  installer now consistently identify the release as version 1.0.0.
