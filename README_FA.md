# ShotLab Desktop 1.0.0

این پروژه نخستین هستهٔ دسکتاپ ShotLab براساس مشخصات محصول تأییدشده است.

## آنچه در نسخهٔ 1.0.0 پیاده‌سازی شده

- برنامهٔ دسکتاپ با PySide6 و Qt
- ایجاد Library فقط با نام
- رابط فارسی و انگلیسی با پشتیبانی RTL و LTR
- رابط نهایی بازطراحی‌شده براساس سند طراحی ۵۵ صفحه‌ای ShotLab
- فونت‌های محلی Inter و Vazirmatn بدون نیاز به اینترنت
- پوستهٔ حرفه‌ای با Sidebar ثابت در سمت چپ، مطابق طراحی نهایی فارسی و انگلیسی
- لوگوی رسمی ShotLab با پشتیبانی خودکار از پوستهٔ روشن و تیره
- آیکون اختصاصی ShotLab برای پنجره، Taskbar و فایل اجرایی ویندوز
- Sidebar قابل Hide با نوار باریک، دکمهٔ بازگشایی و انیمیشن نرم
- آیکون‌های اختصاصی برای پروژه‌ها، کپچر، گالری، خروجی و ورود کتابخانه
- نمایش سازنده و شمارهٔ نسخه در پایین Sidebar
- لوگوی بزرگ‌تر در بالای Sidebar
- حالت روشن و تیره با ذخیرهٔ انتخاب کاربر

- ورود مستقیم به Gallery با دابل‌کلیک روی کارت پروژه
- دو مسیر ورود به پروژه: Timeline و Gallery
- بازیابی آخرین پروژهٔ معتبر از دکمه‌های Capture و Gallery پس از اجرای برنامه
- Video Player و Timeline با Slider بزرگ‌تر

- دکمهٔ مستقیم Gallery Workspace در Toolbar کپچر

## افزونهٔ اختیاری کپچر یوتیوب

افزونهٔ `ShotLab Capture Bridge` یک دکمهٔ هم‌ظاهر با رابط یوتیوب زیر
ویدیوهای معمولی اضافه می‌کند. با فشردن آن، ویدیو روی فریم فعلی متوقف می‌شود،
پلیر در صورت نیاز به محدودهٔ قابل‌دیدن برمی‌گردد، کنترل‌ها و لایه‌های رابط
یوتیوب فقط در لحظهٔ کپچر مخفی می‌شوند و تصویر برش‌خورده مستقیماً به شات‌لب
فرستاده می‌شود.

افزونه فایل یا استریم ویدیو را دانلود نمی‌کند و فریم را به سرویس اینترنتی
نمی‌فرستد. مستندات کامل و نسخهٔ مستقل آن در
[ریپوزیتوری ShotLab Capture Bridge](https://github.com/maisamh80/ShotLab-Capture-Bridge)
قرار دارد.

## تصمیم حریم خصوصی ویدئو

مسیر محلی ویدئو برای هر Library در تنظیمات محلی ShotLab نگهداری می‌شود تا
برنامه در مراجعهٔ بعدی بتواند همان فایل را خودکار باز کند. Schema دیتابیس هیچ
ستون `source_path` یا `video_path` ندارد، Manifest پروژه نام یا مسیر فایل را
ذخیره نمی‌کند و مسیر ویدئو وارد خروجی `.shotlab` نمی‌شود.

پس از خروج از پروژه یا بستن برنامه:

- Media Player از فایل جدا می‌شود.
- خود فایل ویدئو کپی یا وارد دیتابیس نمی‌شود.
- در مراجعهٔ بعدی، مسیر محلی ذخیره‌شده با Fingerprint پروژه بررسی می‌شود.
- اگر فایل هنوز در همان مسیر باشد، خودکار بارگذاری می‌شود.
- اگر فایل جابه‌جا یا حذف شده باشد، برنامه انتخاب دوبارهٔ ویدئو را درخواست
  می‌کند.

## ساختار دادهٔ کاربر

در ویندوز داده‌ها به‌صورت پیش‌فرض در مسیر زیر قرار می‌گیرند:

```text
%LOCALAPPDATA%\ShotLab
```

ساختار هر پروژه:

```text
projects/
└── <project-id>/
    ├── project.json
    ├── captures/
    │   ├── full/
    │   └── thumbnails/
    └── .drafts/
```

## آماده‌سازی نسخهٔ توسعه روی ویندوز

پیش‌نیازهای موقت این نسخه:

- Python 3.11 یا جدیدتر
- FFmpeg در PATH یا پوشهٔ `vendor\ffmpeg`

فقط بار اول اجرا کنید:

```text
setup_windows.bat
```

پس از آن `run_windows.bat` فقط برنامه را باز می‌کند و دیگر Dependency نصب
نمی‌کند یا به اینترنت وصل نمی‌شود.

برای نگهداری یک Cache آفلاین از Dependencyهای ویندوز می‌توان یک بار در حالت
آنلاین فایل زیر را اجرا کرد:

```text
cache_windows_dependencies.bat
```

Wheelها در `vendor\wheels` نگهداری می‌شوند. این Cache به نسخهٔ Python و معماری
Windows وابسته است و به‌دلیل حجم زیاد نباید داخل مخزن عمومی Git قرار بگیرد.

## ساخت نسخهٔ مستقل ویندوز

دو فایل رسمی `ffmpeg.exe` و `ffprobe.exe` را در این مسیر قرار دهید:

```text
vendor/
└── ffmpeg/
    ├── ffmpeg.exe
    └── ffprobe.exe
```

برای ساخت پوشهٔ مستقل دارای فایل `ShotLab.exe` اجرا کنید:

```text
build_windows.bat
```

خروجی در مسیر زیر ساخته می‌شود و برای اجرا به Python، Qt یا اینترنت نیاز ندارد:

```text
dist\ShotLab\ShotLab.exe
```

برای ساخت Portable ZIP و Installer ویندوز، ترجیحاً نسخهٔ ۶۴ بیتی Inno Setup 7
را نصب و سپس اجرا کنید:

```text
publish_windows.bat
```

خروجی‌های قابل انتشار در `release` ساخته می‌شوند. جزئیات امضای دیجیتال و
برطرف‌کردن هشدار Windows در فایل
`docs\WINDOWS_PUBLISHING_FA.md` آمده است.

## اجرای آزمون‌ها

```bat
.venv\Scripts\python -m unittest discover -s quality_assurance -v
```

آزمون‌ها موارد زیر را بررسی می‌کنند:

- فقط نام پروژه الزامی باشد.
- مسیر و نام ویدئو وارد دیتابیس و JSON نشوند.
- Capture همان تصویر نمایش‌داده‌شده و Timecode آن را نگه دارد.
- فقط پالت رنگی استخراج شود و اطلاعات توصیفی خالی و دستی بمانند.
- Search سراسری با داده‌های فارسی و انگلیسی کار کند.
- خروجی و بازیابی کتابخانه، ویدئوی منبع را در خود نگه ندارد.
- Capture قابل ویرایش باشد.
- ویدئوی اشتباه با Fingerprint تشخیص داده شود.

## محدودیت تست این بسته

هستهٔ داده، Search، Backup و جریان Capture با ویدئوی واقعی و FFmpeg تست
شده‌اند. محیط ساخت این بسته Linux و فاقد PySide6 بود؛ بنابراین تست تعاملی رابط
Qt و ساخت فایل Windows باید روی سیستم ویندوز انجام شود.
